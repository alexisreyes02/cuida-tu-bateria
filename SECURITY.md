# Seguridad / Security

## Español

Si encuentras una falla de seguridad en Cuida tu Batería, no abras un issue público.
Escríbenos por el reporte privado de GitHub (pestaña **Security**, botón **Report a vulnerability**)
o al correo info@reyesproject.com con el asunto "Seguridad: Cuida tu Batería".

- Respondemos de lunes a viernes, en un plazo de cinco días hábiles.
- Solo recibe arreglos la última versión publicada en Releases.
- Descarga el instalador únicamente desde la página de Releases de este repositorio y compara su
  SHA-256 con el que aparece en las notas de la versión antes de ejecutarlo.
- El programa no pide contraseñas, no se conecta a cuentas y no envía datos de tu equipo.

## English

If you find a security issue in Cuida tu Batería, please do not open a public issue.
Use GitHub private reporting (the **Security** tab, **Report a vulnerability**)
or write to info@reyesproject.com with the subject "Security: Cuida tu Batería".

- We answer Monday to Friday, within five business days.
- Only the latest version published in Releases receives fixes.
- Download the installer only from this repository's Releases page and compare its SHA-256
  with the one in the release notes before you run it.
- The program does not ask for passwords, does not sign in to any account and does not send data from your computer.
